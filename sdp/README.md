# Convex (LP/SDP) relaxations for lower bounds on magic-state distillation

Exploratory folder (17 Oct 2026). Question: can semidefinite or linear programming give lower bounds on
n_min(tau, d) beyond the exhaustive search and the analytic witnesses of the paper?

## 1. The exact problem is already convex

A stabilizer protocol (any adaptivity, randomness, postselection) has an accepted map Lambda whose Choi
operator J lies in the cone generated by stabilizer states on n + r qubits (each single-Kraus branch has a
pure stabilizer Choi state; this is the core of Theorem 1). Conversely, the extreme rays of that cone are
single branches, so

> an order-d protocol exists  <=>  there is J in cone(STAB_{n+r}) with Lambda(rho_e) proportional to tau
> for every harmless pattern e and Lambda(rho_0) != 0.

This is a *linear* feasibility problem, but over a cone with superexponentially many extreme rays. All the
difficulty is in the stabilizer cone. Consequences:

* **PSD constraints alone are useless.** Without a stabilizer constraint any CP map works (project on
  phi_0, prepare tau). An SDP only helps through an outer approximation of cone(STAB) that it can express.
* **Lower bounds come from outer approximations** K of cone(STAB): infeasibility over K proves that no
  protocol exists.

## 2. Symmetry reduction (one T state)

Twirling the inputs and the output by W = (X+Y)/sqrt2 (a Clifford fixing |T>) and averaging over input
permutations maps a protocol to another protocol with the same harmless set. The result is
"measure each input in the T basis {|T>, Z|T>}, prepare an output diagonal in the same basis":

    Lambda(rho) = sum_e <phi_e|rho|phi_e> ( lam[|e|,0] |T><T| + lam[|e|,1] Z|T><T|Z ),

with 2(n+1) numbers lam >= 0, lam[0,0] = 1 (normalization), lam[v,1] = 0 for v < d (harmless). Its Choi
operator is diagonal in the T basis, so for one T state **every relaxation below is an LP**.

Galois constraint (optional): sqrt2 -> -sqrt2 fixes the Choi operator of a single-branch protocol and swaps
|T> and Z|T>, so complements of harmless patterns output exactly Z|T>: lam[w,0] = 0 for w > n-d. (By
Theorem 1 a single branch suffices, so this is without loss of generality.)

## 3. The level-k hierarchy

For every stabilizer state s on n-k of the inputs, contracting J with s (a postselected stabilizer
projection) must leave an operator on the remaining k inputs and the output in cone(STAB_{k+1}). Because J
depends only on fault weights, the contraction depends on s only through its T-basis weight distribution
m_v(s) = sum_{|e|=v} |<phi_e|s>|^2:

    g_s(j,b) = C(k,j) sum_v m_v(s) lam[j+v, b]   in   cone{ agg d(s') : s' stabilizer on k+1 qubits }.

* The right-hand cone is computed **exactly** by enumerating all stabilizer states on k+1 <= 5 qubits
  (`stab_enum.py`; counts 6, 60, 1080, 36720, 2423520 reproduced) and their T-basis distributions.
* Any family of conditioning states s gives **valid** constraints (fewer states = weaker, never wrong).
  We use all stabilizer states for n-k <= 5, and products plus random Dehaene-De Moor states above.
* Level k = n (no conditioning) is exact; level 0 is exactly the paper's pure-stabilizer witness argument.

Also tested: the Pauli-l1 ("stabilizer norm") outer approximation sum_P |Tr JP| <= 2^N Tr J
(`t_l1.py`). It only reproduces the trivial n >= d and is not useful.

## 4. Results (one T state, numerical LP)

Smallest n **not** excluded (so n_min(T,d) >= that value):

| d | levels 1,2,3 | + Galois | level 1 only | exhaustive search (paper) | analytic (paper) |
|---|---|---|---|---|---|
| 2 | 4 | 4 | 4 | **9** (exact) | 2 |
| 3 | 6 | 6 | 6 | 9 | 3 |
| 4 | 8 | 8 | 7 | 9 | 4 |
| 5 | **10** | 10 | 9 | 9 | 5 |
| 6 | **12** (n = 10, 11 excluded; 4000 conditioning states) |  |  | 9 | 6 |
| 7, 8 | running (`results_scan_big.txt`) |  |  | 9 | 7, 8 |

* The relaxation gives **n >= 2d for one T state** for d = 2..6, against n >= d analytically. For d >= 5
  this beats the exhaustive bound of 9: **n_min(T,5) >= 10 and n_min(T,6) >= 12** would be new.
* Level 4 (5-qubit cone, `t_lp.py`) adds nothing beyond its exact case n = 4 at d = 2.
* Validation (`validate.py`): the twirled Choi vector of the nine-input T factory satisfies every
  constraint, and reproduces its leading coefficient C(9,2) lam[2,1] = 36 x 0.375 = 27/2. So does the
  trivial one-input protocol.
* Certificates (`certificate.py`) are small (5-8 constraints at level 1) and use structured witnesses:
  singlets (weight exactly one in the T basis), Bell pairs and |+>, |-> products, against the facets of the
  2-qubit stabilizer cone. This suggests an analytic proof of n >= 2d for one T state, the analogue of
  n >= 2d+1 for rational targets but without the complementary-fault symmetry.

**Robustness caveat (`robust.py`).** The exclusions are *degenerate*: weakening every facet by delta = 1e-6
makes the infeasible cases feasible. The proofs therefore rest on exact zeros (a singlet has exactly zero
weight on 0 and 2 faults; facets are exactly tight on some generators), not on a numerical margin. This is
valid mathematics but must be confirmed in exact arithmetic. It also explains the mechanism: projecting two
inputs onto a singlet always adds exactly one fault, so at n = 2d-1 it forces weight-d patterns to output
exactly Z|T>; such zero-propagation chains are the same kind of argument as the paper's witnesses.

## 5. Status and next steps

1. **Rigor.** Results are floating-point LPs. To use them in the paper: rationalize the facets (shrink
   slightly so they stay valid against the exact Q(sqrt2) generators) and verify the small Farkas
   certificates in exact arithmetic.
2. **Analytic proof** of n_min(T,d) >= 2d from the singlet/|+> certificate pattern.
3. **Rational targets** (CS, CCZ): same hierarchy, but the output cannot be fully dephased; twirl it by the
   Clifford automorphisms of tau and use the (k+r)-qubit cone (k <= 2 for CCZ, k <= 3 for CS). The paper
   already has n >= 2d+1 there, so the question is whether the relaxation improves the constant.
4. Stronger outer approximations of cone(STAB) (Clifford-commutant / multi-copy extensions in the style of
   Gross-Nezami-Walter) are possible but large; not attempted.
